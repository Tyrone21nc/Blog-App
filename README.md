# Blog-App
A Blog App

I have uploaded a pdf to my notes.

If you want to run the application. Fork the repo on VSCode and then from the terminal, navigate to the django_blog/ folder. 
1. You should already have a virtual environment, but if you don't run this: <code>python -m venv .venv</code> and then activate it <code>.venv\Scripts\activate</code>
2. Install Django on your directory (assuming you already have the latest version of python) <code>pip install django</code>
3. Then run the project: <code>python manage.py runserver</code>

If you run into some issues, please refer to the Learning Django.pdf document on the setting up part. It should include a lot more details especially for non Windows users.
